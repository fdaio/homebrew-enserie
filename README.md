# fdaio/homebrew-tap

```bash
brew tap fdaio/enserie
brew install fdaio/enserie/ens
```

The formula is generated from the release tarball by
`scripts/homebrew-formula.sh` in [fdaio/enserie](https://github.com/fdaio/enserie),
and each release publishes its own copy as an `ens.rb` asset. This repository
holds the current one.

TUN setup needs root, so run `ens` with `sudo` even when it came from brew.
